✨ Características

  • Blur Effect: backdrop-filter con soporte iOS Safari
  • Glassmorphism: Card semi-transparente con blur
  • Bloqueo de Scroll: Previene scroll del body (incluye fix para iOS)
  • 3 Variantes: Dots (iOS), Simple, Material
  • Estado de Éxito: Checkmark animado verde
  • Responsive: Se adapta a móvil y desktop
  • Animaciones Suaves: Cubic-bezier naturales

💡 Recomendaciones de Uso

  • Usa Dots Bounce para la mayoría de operaciones (estilo iOS)
  • Usa Simple para operaciones rápidas (< 2s)
  • Usa Material para operaciones largas (> 5s)
  • Muestra estado de éxito para confirmar acciones importantes
  • En móvil, evita permitir cierre durante operaciones críticas
